# 演示视频拍摄脚本（3-5 分钟）

> 配合《项目说明文档》第九节。供录制参赛演示视频使用（录屏 + 截图 + 口播）。

## 准备工作

- 启动服务：双击 `start.bat`（脚本会自动用 .venv，浏览器打开 http://127.0.0.1:8000）
- 录屏软件建议开启 1920x1080，光标可见；口播用清晰女/男声均可
- 准备 1-2 张校园宣传栏/展板真实照片（建议用 `data/uploads/` 已有测试图）

## 分镜与口播稿

| 时间 | 画面 | 口播稿（建议） |
|---|---|---|
| 0:00-0:30 | 封面字卡 + 项目主页面俯拍 | 「华泰杯 · AR 视觉识别智能体：一段理论脚本 + 一张校园展板照片 = 一支带 AI 配音的 AR 宣传短视频。这也是本届校园生活赛道 AR 视频创作命题的参赛作品。」 |
| 0:30-1:15 | 页面「录入脚本」，粘贴宣讲稿，点生成分镜 | 「我们把‘总体国家安全观’宣讲稿粘贴进去，点生成分镜。本地方言模型 Qwen2.5-0.5B 会自动把脚本拆成 3-6 个镜头，每个镜头有画面、旁白和 AR 叠加元素。」 |
| 1:15-2:00 | 上传校园展板照片，展示 OCR 结果 | 「再上传一张校园宣传栏实拍图，系统自动 OCR 识别文字，并标注政治文化属性——比如这一张命中‘总体国家安全观’，AR 素材就会用蓝色国安主题。」 |
| 2:00-3:00 | 选择分镜 + 场景，点合成，等待轮询到完成，下载成片并播放 | 「选中分镜和场景，一键合成。系统会自动叠加 AR 素材、生成字幕条、合成晓晓女声旁白，最后输出可直接投稿的 mp4。」 |
| 3:00-3:30 | 内容审核页：跑一次审核，展示记录 | 「政治理论类内容敏感，系统内置敏感词 + 本地大模型语义复核，并保留人工终审记录，确保合规。」 |
| 3:30-4:00 | 运行 `scripts/smoke_test.py` 展示全链路自测 | 「我们还准备了一键自测脚本，28 条用例全链路回归，全部实测通过。」 |

## 注意

- AI 配音走微软 edge-tts 在线服务，录制时保证联网；离线会自动降级为无配音成片（可在视频中说明）。
- 若录制现场无真实展板照片，可先向 `data/uploads` 导入测试图。
- 完整用例与修复记录见 `docs/测试用例集.md`、`审查与修复总结报告.md`。
