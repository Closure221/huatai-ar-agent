# 合规说明

> 配套《华泰杯 · AR 视觉识别智能体》提交材料。本文档说明系统在数据来源、个人隐私、内容安全、版权与网络依赖等方面的合规设计。

## 1. 数据来源与类型

系统处理的数据仅有两类，均由参赛者/使用者主动提供：

| 数据 | 来源 | 用途 |
|---|---|---|
| 理论宣讲脚本（文本） | 用户在 Web 页面手动输入 | 分镜生成、要点提取、内容审核 |
| 校园场景照片（图片） | 用户手动上传（jpg/png/webp/bmp，≤10MB） | OCR 文字识别、政治文化属性解析、AR 视频背景 |

系统不主动采集任何数据，不公开收集或爬取第三方数据。

## 2. 数据处理与存储

- 全部数据存储在**本机**：SQLite 数据库 `data/huatai_ar.db`，上传图片存 `data/uploads/`，成片存 `data/outputs/`，素材存 `data/assets/`。
- 图像识别（OCR）、分镜生成（Qwen2.5-0.5B）、AR 素材绘制、视频合成都为**本地推理**，识别结果不上传第三方。
- 不存在云端账号系统，无用户注册与登录，无 Cookie 追踪。

## 3. 个人隐私

- 系统不采集姓名、学号、手机号、定位、设备指纹等个人身份信息。
- 上传的场景照片仅用于本次识别与合成，不录入人脸识别/身份识别。
- 照片与脚本均存于本机授权目录，团队可随时手动删除。

## 4. 内容安全与审核

- 面向政治理论学习场景，内置**两级审核**：
  1. 自动审核：敏感词规则 + 本地 LLM 语义复核，识别不当表述/违规内容；
  2. 人工终审：自动审核仅作辅助，**最终政治内容发布合规责任由人工终审承担**，系统前端保留审核记录。
- 输入提示与帮助文案中明确告知使用者：发布前须人工确认内容准确、合法、合规。

## 5. 版权与模型合规

- 本地大语言模型 **Qwen2.5-0.5B-Instruct** 遵循 Apache-2.0/Qwen 开源协议，仅用于本项目本地推理，不对外部署服务。
- AR 叠加素材由系统程序化绘制（PIL 生成主题卡片/横幅/图表），不引用第三方版权图片；用户上传的场景图版权归上传者所有，仅在本机使用。
- 未使用任何盗版或未经授权素材。

## 6. 网络依赖

| 环节 | 是否联网 | 说明 |
|---|---|---|
| 首次安装依赖 | 是 | pip 安装 Python 包（PyPI / PyTorch CPU 源） |
| 场景识别/分镜/合成/审核 | 否 | 全部本地推理 |
| AI 配音（edge-tts） | 是 | 调用微软在线 TTS；**离线自动降级**为无配音成片，不阻塞出片 |
| 一键自测 | 否 | 本地全链路 |

## 7. 数据留存与处置

- 无自动上传、无匿名统计回传。
- 全部运行数据位于项目 `data/` 目录，可整体删除即完成数据清除。

## 8. 责任声明

- 本项目为高校创新竞赛参赛作品，用于校园学习与宣传演示。
- 生成内容涉及政治理论时，使用者须依据宣传纪律进行人工把关后发布。
- 赛事组织方要求的其它合规事项，以赛事官方说明为准。
